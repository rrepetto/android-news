# Android Security Digest

Resumen diario automatizado de novedades de seguridad del ecosistema Android.

## Feed RSS

Suscribite al feed para recibir las novedades del día:

**URL del feed:** `https://raw.githubusercontent.com/rrepetto/android-news/claude/digest/feed.xml`

> El feed RSS contiene **solo los ítems del último día** (actualizado en cada corrida diaria). El historial completo está en la carpeta [`digests/`](digests/).
