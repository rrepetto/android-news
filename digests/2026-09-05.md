# Android Security Digest — 2026-09-05

## 🔴 Alta relevancia

- **CVE-2026-85046: Chrome para Android V8 zero-day explotado activamente** — Vulnerabilidad de type confusion en el motor V8 de Chrome (CVSS 8.8) que permite ejecución de código dentro del sandbox del navegador mediante contenido web malicioso. Parcheada el 3 de septiembre de 2026 en Chrome 152.0.7977.82 para Android; Google confirma explotación activa en la naturaleza. Es el 6.° zero-day de Chrome en 2026. Actualizar Chrome inmediatamente. [fuente](https://thehackernews.com/2026/09/google-releases-chrome-update-to-patch.html)

## 🟠 Media relevancia

- **Magisk v31.0 lanzado (4 septiembre 2026)** — Nueva versión mayor de Magisk: UI completamente reescrita con Jetpack Compose + Material 3, emulador de terminal integrado (TTY/ANSI), soporte para Android 17 (API 37), streaming de boot images desde URLs OTA remotas. Cambio relevante para seguridad: la DenyList ahora incluye `webview_zygote` como destino de desmontaje, ampliando el ocultamiento de root en apps basadas en WebView. [fuente](https://github.com/topjohnwu/Magisk/releases/tag/v31.0)

En el frente de seguridad: Play Protect suma verificaciones adicionales para apps no verificadas, alineado con el enforcement de API 36 activo desde el 1 de septiembre.
