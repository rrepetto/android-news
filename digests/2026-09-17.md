# Android Security Digest — 2026-09-17

## 🔴 Alta relevancia

- **RatHat: troyano Android encadena Accessibility + Wireless ADB + IA para robar credenciales bancarias** — Nuevo malware bancario Android descubierto el 17 de septiembre de 2026. Utiliza Accessibility Services para activar Developer Options y Wireless Debugging de forma automática, obtiene el código ADB de emparejamiento de la pantalla y se conecta al daemon ADB local del dispositivo, consiguiendo acceso a shell sin necesidad de PC. Despliega dos binarios Go encubiertos como librerías nativas (`liblocal-service.so` como agente privilegiado y `libmedia_codec.so` como túnel FRP al C2). Emplea IA generativa para automatizar la navegación en pantalla. Roba PINs, OTPs, patrones de desbloqueo y credenciales bancarias mediante overlays HTML, keylogging vía Accessibility y captura de pantalla. Se reinstala a sí mismo tras borrado manual gracias a los privilegios ADB adquiridos. Se distribuye por smishing, anuncios maliciosos y APKs falsas (disfrazadas de apps de streaming o Chrome). Vinculado a actores de amenaza con base en China. [GBHackers](https://gbhackers.com/rathat-malware-attack/)
