# Android Security Digest — 2026-08-23

## 🔴 Alta relevancia

- **Primer malware documentado para Android car head units — cadena de suministro MoYu/BadBox** — Kaspersky descubrió el primer caso documentado de malware diseñado específicamente para sistemas Android de infoentretenimiento vehicular (car head units). Se propaga a través de TWCore, el actualizador oficial de DoFun (Shenzhen Driving Control), instalando el dropper JarService que convierte los dispositivos en nodos de botnet proxy y herramientas de fraude publicitario. Atribuido con alta confianza al grupo MoYu, actor previamente vinculado al ecosistema BADBOX. [The Hacker News](https://thehackernews.com/2026/08/android-car-malware-spreads-through.html) / [Securelist (Kaspersky)](https://securelist.com/android-head-unit-malware/121106/)
