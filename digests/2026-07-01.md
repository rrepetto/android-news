# Android Security Digest — 2026-07-01

## 🔴 Alta relevancia

- **Google implementa RBUS: el ASB mensual ahora solo lista vulnerabilidades de alto riesgo** — Google introdujo el Risk-Based Update System (RBUS): solo CVEs bajo explotación activa o en cadenas de exploit reciben parches mensuales; el resto se acumula en boletines trimestrales (mar/jun/sep/dic). El ASB de julio 2025 fue el primero en quedar vacío bajo este esquema; el de julio 2026, próximo a publicarse, podría seguir el mismo patrón. Impacta todo el ciclo de parcheo del ecosistema Android. [fuente](https://www.androidauthority.com/android-risk-based-security-updates-3597466/)

## 🟠 Media relevancia

- **GrapheneOS y CalyxOS publican actualizaciones de seguridad con parches de julio 2026** — Ambas distribuciones enfocadas en privacidad publicaron actualizaciones que incluyen los parches del ASB de julio 2026, adelantando a la mayoría de los OEMs; GrapheneOS incorpora los parches previamente en sus security preview releases bajo acuerdo con Google. [fuente](https://www.nobsbitcoin.com/grapheneos-and-calyxos-july-security-updates-released/)

- **Android Developer ID Status API lanza globalmente en julio 2026** — Google lanza en julio la Developer ID Status API (permite verificar si un package name está registrado) y abre early access para la Developer Console API (registro y gestión vía CI/CD); las tiendas de apps de terceros pueden integrarlas para bloquear apps de desarrolladores no verificados, reforzando la cadena de suministro de aplicaciones. [fuente](https://android-developers.googleblog.com/2026/06/android-developer-verification.html)
