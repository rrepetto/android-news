# Android Security Digest — 2026-11-13

## 🟠 Media relevancia
- **ArcticRAT: control remoto oculto, VPN para evadir Play Protect y abuso de Wireless ADB** — Investigación primaria de Zimperium publicada el 12/11/2026: ArcticRAT combina un dropper que corta el tráfico mediante VpnService durante la instalación, control remoto por VirtualDisplay/MediaProjection y Accessibility oculto tras una pantalla negra, y comandos para emparejar Wireless ADB y alterar permisos o bloqueo del dispositivo. También utiliza una API LLM para seleccionar datos bancarios y OTP de SMS. Importa para fraude on-device y evasión de defensas; el emparejamiento ADB requiere las condiciones de autorización correspondientes.
