# Android Security Digest — 2026-09-14

## 🔴 Alta relevancia

- **ShinyHunters y grupos APT abusaron de Claude para extraer secretos de 1.8M de APKs de Android** — El colectivo ShinyHunters (alias frkoo/blazespider) junto con Midnight Blizzard (APT29) y GTG-10007 desplegaron una infraestructura de 10 workers en AWS EC2 para descargar, decompile y escanear con TruffleHog 1.8 millones de APKs de Android, extrayendo credenciales, API keys y tokens hardcodeados en el código fuente. Claude fue usado para automatizar el pipeline. Anthropic publicó su informe de amenazas de septiembre 2026, baneó las cuentas y notificó a las partes afectadas. Demuestra el riesgo de secretos hardcodeados en apps y el abuso de GenAI para exfiltración masiva a escala industrial. [fuente](https://www.bleepingcomputer.com/news/security/hackers-abused-claude-to-extract-secrets-from-18m-android-apps/)

- **OEMpocalypse: exploit de root sin permisos contra drivers OEM de Samsung, Xiaomi y Oppo** — Investigación publicada el 31 de agosto por Lukas Maar (Calif.io) demuestra cómo CVE-2026-43499 (GhostLock) puede explotarse a través de drivers kernel OEM-específicos (Samsung One UI, Xiaomi HyperOS, Oppo/OnePlus ColorOS) mediante una APK sin ningún permiso declarado, sobre firmware de julio 2026 con bootloader bloqueado y Verified Boot activo. El PoC público en GitHub ("GhostLock") ya incluye evasión de Play Integrity API a través de KernelSU. Afecta Galaxy S23–S26, flagships Xiaomi y Oppo/OnePlus/Realme. [fuente](https://blog.calif.io/p/oempocalypse-now)

## 🟠 Media relevancia

- **MediaTek Security Bulletin — Septiembre 2026** — Boletín mensual publicado el 7 de septiembre con 15 CVEs (5 High, 10 Medium) que afectan distintos SoCs de MediaTek. Los OEMs fueron notificados con al menos dos meses de anticipación. MediaTek reporta que no hay explotación activa conocida en la naturaleza. Las correcciones están incluidas en el parche Android 2026-09-05. [fuente](https://www.mediatek.com/product-security-bulletin/September-2026)

## 🟡 Baja relevancia / notas

- **Samsung Galaxy S26 — One UI 9 estable aún no liberado al 14 de septiembre** — A pesar de que Samsung había anunciado el rollout para mediados de septiembre, al 14 de septiembre el update estable de One UI 9 para el S26/S26+/S26 Ultra no fue liberado aún según múltiples reportes de usuarios. Samsung no confirmó nueva fecha. [fuente](https://r2.community.samsung.com/t5/Galaxy-S/September-14th-and-they-still-couldn-t-release-the-0ne-ui-9/m-p/22874155)
