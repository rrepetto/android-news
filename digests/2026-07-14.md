# Android Security Digest — 2026-07-14

## 🔴 Alta relevancia

- **RedHook Android RAT: abusa de Wireless ADB para obtener acceso shell sin root ni PC** — Nueva versión del RAT RedHook (analizado por Group-IB) engaña al usuario para que otorgue permisos de Accessibility, luego activa Developer Options + Wireless Debugging de forma automática y se conecta al daemon ADB local (127.0.0.1), obteniendo privilegios de shell (uid 2000) sin necesidad de PC ni root. Usa internamente un framework basado en Shizuku para ejecutar comandos, instalar/desinstalar apps y modificar ajustes protegidos sin diálogos visibles. Originalmente dirigido a Vietnam, ya se expande a Indonesia. [BleepingComputer / Group-IB](https://www.bleepingcomputer.com/news/security/redhook-android-malware-now-uses-wireless-adb-for-shell-access/)
