# Android Security Digest — 2026-07-02

## 🔴 Alta relevancia

- **Ransomware de navegador generado por IA (DeepSeek) cifra archivos en Android Chrome sin instalar nada** — Check Point Research documentó el primer caso de ransomware browser-only generado con IA (DeepSeek/InfernoGrabber v9.0): abusa de la File System Access API de Chromium para enumerar, leer, exfiltrar y cifrar archivos del usuario desde una web trampa, sin payload nativo, sin root y sin explotar ninguna vulnerabilidad. Funciona en Android Chrome y Windows. Marca un nuevo vector de ataque de bajo umbral y alta evasión. [fuente](https://thehackernews.com/2026/07/ai-generated-browser-ransomware-abuses.html)

## 🟠 Media relevancia

- **Android 17 QPR1 Beta 6 alcanza Platform Stability — APIs del Feature Drop de septiembre están bloqueadas** — Google publicó Beta 6 de Android 17 QPR1 para Pixel (build CP31.260618.005, julio 1) declarando Platform Stability: la superficie de APIs queda congelada y los desarrolladores pueden ya optimizar sus apps para el Feature Drop de septiembre. Incluye mejoras en desktop windowing (barra de tareas flotante) y Health Connect (seguimiento automático de distancia/calorías). [fuente](https://9to5google.com/2026/07/01/android-17-qpr1-beta-6-pixel/)

## 🟡 Baja relevancia / notas

- **Samsung extiende el parche de junio 2026 al Galaxy S23 FE y más dispositivos ya en julio** — Samsung desplegó el parche de seguridad de junio 2026 (45 vulnerabilidades, incluyendo el zero-day CVE-2025-48595) al Galaxy S23 FE (firmware S711BXXSGGZF2, ~282 MB) y dispositivos adicionales con el mes ya cambiado a julio, indicando adopción tardía del parche crítico con explotación activa confirmada. [fuente](https://www.androidheadlines.com/2026/07/samsungs-june-2026-security-update-just-reached-more-galaxy-devices.html)
